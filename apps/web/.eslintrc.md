# Pourquoi `react/no-unescaped-entities` est désactivée

La règle signalait **78 erreurs, toutes identiques** : des apostrophes dans du texte
français en JSX (`l'annuaire`, `d'achat`). Elle existe pour attraper une guillemet JSX
oubliée ; sur un site rédigé en français, elle ne fait que réclamer `&apos;` à chaque
mot élidé, ce qui dégrade la lisibilité du code sans rien protéger.

Décision du 16 septembre 2026 (REBUILD.md T6.6). Les autres règles de
`next/core-web-vitals` restent actives. Avertissements connus et assumés :
`@next/next/no-img-element` sur les favicons de 64 px (T4.10), et deux `jsx-a11y/alt-text`
qui prennent l'icône lucide `<Image>` pour une image.
